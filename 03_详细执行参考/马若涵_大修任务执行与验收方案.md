## 3. 具体执行方案

### M01 原始材料审计

**对应审稿意见：** R2-1。


1. 从原稿实际引用命令和BibTeX核对文献标识，区分正文引用、参考文献条目与候选证据研究。
2. 清点原检索式、导出文件、去重记录、全文及筛选记录是否存在。
3. 对实际找到的引用条目分配记录ID，再按是否同一研究建立study_id映射，记录标题、作者、年份、DOI/URL和原稿位置。165是待核对的原稿声称，不预填165条，也不将报告数量直接等同于独立研究数量。
4. 区分“可追溯原始过程”“只有引用记录”“需要重检”。不能从最终参考文献数量倒推历史检索流程。

交付：`baseline_references.csv`、`search_record_gaps.md`。

验收：165这一原稿声称的数量已与实际引用核对，差异有说明；缺失材料明确，不编造历史记录。冯宗林抽查。

### M02 制定检索协议

**对应审稿意见：** R2-1。


1. 写研究问题：BBR版本、适用环境、公平性、跨协议共存及AI优化分别需要什么证据。
2. 选择实际可访问的数据库与补充来源，说明不同来源用途；数据库检索与源码/技术报告手工检索分开记录。
3. 起草分组关键词，例如BBR及版本名称，与fairness、RTT、buffer、wireless、satellite等主题词组合；补充BDP-Veno和OVeno专门检索。该示例不是已验证可用的数据库语法。
4. 在每个平台调试语法，用若干已知相关文献检查覆盖情况，保存最终原样检索式和日期。
5. 预设语言、时间、文献类型、主题相关性、最低方法信息等纳入/排除规则；“已在正文引用”不得作为纳入条件。
6. 冯宗林确认后冻结协议。后续修改留下版本、理由和影响范围。

交付：`search_protocol_v1.md`。

验收：另一人能按协议重复操作；检索日期与范围明确；标准独立于最终引用集合。

### M03 执行检索与导出

**对应审稿意见：** R2-1。


1. 按冻结协议逐库检索，保存完整导出文件，避免只保存搜索页截图。
2. 每次记录库名、检索式、时间、显示结果数、实际导出数、导出限制和文件名。
3. 如果有条数上限，分批导出并记录批次；区分显示命中数量与实际取得的记录。
4. 追溯引用、人工检索和源码资料单独登记来源，不能混入数据库计数。

交付：`search_log.csv`、`raw_exports/`。

验收：每个计数有对应记录；分批不重不漏或明确限制；不能以拟定的165作为必须凑齐的最终数。

### M04 去重和筛选

**对应审稿意见：** R2-1。


1. 保留原始导出，用统一DOI、标题、作者和年份检测重复；标题近似的记录人工核对。
2. 保存每个原始record_id到保留study_id的映射和去重理由。
3. 标题/摘要筛选后再全文筛选。全文排除记录一个主要理由，可附次要说明。
4. 没拿到全文标记“未取得”，不要伪装成已全文审查。
5. 模糊案例交冯宗林裁定，记录裁定理由。全文无法访问时先寻找合法公开版本；仍不可得则登记缺失。
6. 邀请冯宗林抽查至少5条纳入与5条排除记录，不足5条则全查；如发现规则性错误，扩展复核同类记录。正文如实写筛选人和复核方式，不声称全量双人独立筛选。

交付：`dedup_map.csv`、`screening_log.csv`。

验收：每条记录有去向；排除理由与预设标准一致；争议裁定完成；原始导出保持不变。

### M05 流程图及计数

**对应审稿意见：** R2-1。


1. 从记录表计算初检、去重、题摘筛选、全文获取、全文评估和最终纳入数量。
2. 核对各阶段的输入、输出、排除与未获取数量能对账；计数单位注明是记录、报告还是研究。
3. 数据库与其他途径分开显示，保留同一研究多报告关系。
4. 输出可编辑流程图数据和方法说明，供刘庭佳排版。

交付：`selection_counts.csv`、流程图源文件、数量核对记录。

验收：图、表、正文的数字一致；每个数字能从筛选表重新计算。

### M06 框架证据提取

**对应审稿意见：** R1-M3、M4；R2-2；支撑R1-M1、M2。


证据表至少包含：study_id、来源页码/图表、研究类型、协议实现版本、带宽、RTT、缓冲区绝对值与BDP口径、队列管理、流数量、丢包条件、指标、结果、重复/统计说明、限制。

1. 先提取被审稿人点名的结论，特别是缓冲区边界、异构RTT、ECN及LEO分类。
2. 数值抄录与自己计算分开；计算保留公式和输入。未报告填NR，不猜数。
3. 从图中读取近似值必须标“图中估读”，说明方法与精度，不能作为精确原始测量。
4. 记录外部可比性问题，不跨不同场景直接合并为普适阈值。
5. 配合冯宗林划分框架构建材料与留出验证材料，避免重复研究造成信息泄漏。

交付：`evidence_matrix.csv`、`framework_evidence_notes.md`。

验收：关键数据可定位原文；NR和估读清晰；构建/验证标记明确；10/1前交付核心条目，扩展文献随后补齐。

### M07 比较既有综述与新增研究

**对应审稿意见：** R1-M5、M6；R3-2、3。


1. 确认原稿[20]对应的稳定文献ID，不能在修订后继续仅靠旧编号定位。
2. 比较既有综述的问题定义、版本范围、证据方法、场景、机制解释、决策规则和验证。
3. 每个“本文新增”都指向本轮实际交付，避免只写覆盖更多场景。
4. 阅读BDP-Veno/OVeno原始研究，整理其目标、估计量、控制思路、场景及与BBR关系；证据不足时不声称性能优劣。
5. AI研究逐篇记录目标函数、公平性指标、服务差异处理和实验环境；区分某项研究未做与软件本身不能做。

交付：`survey_comparison.csv`、补充文献正文、AI主张证据表。

验收：比较均有来源位置；“多数/全部/没有”有明确分母和范围，否则改为本文纳入研究中的具体观察。

### M08 方法与回复交付

**对应审稿意见：** R2-1；R1-M5、M6；R3-2；支撑R3-3。


方法节写实际执行过程和限制，附检索式、筛选说明、证据表目录。对R2-1、R1-M5、R1-M6、R3-2分别写“问题—动作—证据—正文位置”。10/12依据最终稿更新位置。

验收：正文和补充材料互相对账；没有把计划写成已执行；回复不夸大复核或检索范围。冯宗林验收后合并。

### M09 文献交付前自检

**对应审稿意见：** 内部质量检查；复核R2-1、R1-M5、M6及R3-2。


逐一检查正文引文与BibTeX匹配，删除/新增文献引起的编号变化，关键数值定位及检索流程计数。只处理有依据的更正，记录返工项。

验收：无未定义引文；关键来源可找到；最终稿、图、补充表和回复一致。

## 5. 首次开工、表格字段与交付示例

### 5.1 第一轮先做什么

1. 打开原稿cas-sc-template.tex和refs.bib，列出正文实际引用的key，生成baseline_references.csv。
2. 向冯宗林列出需要找回的原检索文件；有就登记来源，没有就登记缺失。
3. 先提交这两份清单，再提交search_protocol_v1.md；协议尚未冻结时可以试检索，但不把它记成正式筛选结果。
4. 9/30先交完整检索与筛选记录，10/1优先交框架依赖的证据；若全文获取未完成，明确剩余数量与影响，不能把暂时数量写成终值。

### 5.2 文件必须包含哪些列

| 文件 | 必填字段 |
|---|---|
| baseline_references.csv | citation_key、study_id、标题、年份、DOI/URL、正文位置、是否有全文、原检索记录状态 |
| search_log.csv | search_id、数据库/来源、检索日期、完整检索式、筛选条件、显示命中数、实际导出数、导出文件 |
| dedup_map.csv | 原record_id、保留record_id、study_id、是否重复、判断依据 |
| screening_log.csv | record_id、study_id、题摘决定、全文是否取得、全文决定、主要排除理由、执行人、日期、争议处理 |
| evidence_matrix.csv | study_id、具体主张、来源页/图/表、版本、带宽、RTT、队列、流数、指标与单位、结果、NR项、局限、构建/验证用途 |

每个单元格必须能区分“文献没有报告（NR）”“尚未查明（待核）”“不适用（NA）”，不以空白混淆三种情况。CSV统一UTF-8，长文本正确引用，不能因逗号把一条记录拆错列。

### 5.3 一条证据怎样算合格

合格结构示例（以下是填写格式，不是实际研究结果）：

> study_id=Sxxx；原文Table X，第Y页；固定实现=原文记录；带宽/RTT/缓冲区=原文值；指标=原文定义；数值=原文值；结论只适用于这些条件；缺失版本信息=NR。

不合格示例：“某篇论文证明BBR更公平”，但没有页码、条件、指标或数值来源。

### 5.4 交给谁、谁能开始后续工作

- 给冯宗林：核心证据矩阵、无法支撑的主张清单，供框架定义与机制核查。
- 给刘庭佳：已对账的流程图节点数字及解释，不能只给截图让其猜流程。
- 给冯宗林统稿：可直接合并的方法段、比较段与逐点回复；不要只交文献链接。
- 原始检索记录不齐、筛选数量不对、证据只写摘要而无定位，均退回补齐。文献真的未报告的参数可标NR通过，但不能据此支持依赖该参数的确定性结论。
