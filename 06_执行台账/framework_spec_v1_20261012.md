# 三维框架规范 F07-v1（可复制验收版）

## 输入

瓶颈容量、参考 RTT、每流 RTT、绝对缓冲区、缓冲区/参考 BDP、丢包来源、ECN、BBR实现、队列管理和流数。

## 输出

分别报告吞吐、时延、公平性和重传。证据不足或指标不适用时使用 `undetermined` 或 `not_applicable`，不合成无定义的总分。

## 判定

- `support`：观测方向与冻结预测一致；
- `contradict`：观测方向明确相反；
- `undetermined`：波动、缺失或适用条件不足；
- `not_applicable`：案例没有触发对应机制或不满足输入条件。

## 独立性

F07-v1 预测文件先于 E3 观测保存。E1/E2/E3 结果不能追溯性地改写 v1 规则；规则变化必须另存 v2。
